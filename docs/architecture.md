# 系统架构

## 设计目标

Inventory Art 是一个多租户模块化单体，服务于展会结束后的人工销售数据补录。系统只建模纸笔记录能够支撑的事实，避免在金额和商品数量之间制造无法验证的关联。

```text
Vue 单页应用
      │ REST/JSON
Spring Boot 模块化单体
      ├── PostgreSQL（业务数据、审计）
      └── 本地或 S3 兼容存储（商品图片）
```

## 业务边界

| 模块                       | 职责                              |
| -------------------------- | --------------------------------- |
| `auth` / `user` / `tenant` | 登录、令牌、用户和 Tenant 配置    |
| `event`                    | 展会日期范围和启用状态            |
| `order`                    | 展会小时金额记录、编辑和删除      |
| `product`                  | 商品目录、标准售价和成本资料      |
| `inventory`                | 库存流水、精确修正和商品销量批次  |
| `expense`                  | Tenant 共享支出类别与展会支出     |
| `report`                   | 金额与数量两套独立聚合            |
| `storage`                  | 商品图片元数据和对象访问          |
| `admin` / `audit`          | Tenant 与账号管理、管理员操作审计 |

收入报表读取 `orders`，支出报表读取有效的展会支出；展会结余仅为两者之差。商品报表和商品累计销量读取有效售出批次的当前明细。不可变库存流水保留原始售出、更正和冲销过程，但技术流水不重复进入业务列表或报表。商品标准售价与成本不参与成交收入或结余计算。

## 交易写入

前端选择展会和小时后提交 1 至 100 个正数金额。后端完成以下校验：

1. 展会属于当前 Tenant 且可用。
2. 输入时间按 Tenant 时区截断到整点。
3. 截断后的本地日期位于展会日期范围内。
4. 币种取 Tenant 默认币种。
5. 整批在一个事务内写入，任一金额非法则全部失败。

每笔记录拥有独立系统订单号，后续可单独编辑或删除。列表支持在当前页选择多笔交易后原子删除；任一 ID 不存在或不属于当前 Tenant 时整批回滚。

## 商品销量写入

销量请求只包含展会和商品数量。销量归属日期为展会结束日。后端在同一事务中按商品 ID 固定顺序锁定并扣减库存、创建销量批次、当前明细和 `SALE` 流水；重复商品会被拒绝，任一商品库存不足则整批回滚。

售出修改可替换展会和全部商品明细，并按新旧数量差写入 `SALE_CORRECTION` 流水。永久撤销写入 `SALE_REVERSAL` 流水恢复库存并把批次标记为 `CANCELLED`。业务列表、CSV、商品销量和报表只读取最终有效明细。

展会支出使用 Tenant 级自定义类别。类别可改名、停用和重新启用；支出可修改或作废，均保留审计历史。支出币种是创建时 Tenant 默认币种的快照，报表按展会结束日归属。

普通库存操作支持新增、减少和精确修正，并保留操作备注、操作人和审计记录。

## 时间与币种

- 数据库时间戳统一保存为 UTC。
- Tenant 保存时区，交易小时的解释和展会日期校验使用该时区。
- Tenant 默认币种在交易创建时写入订单，保证历史数据不受之后配置变化影响。
- 支出也在创建时保存 Tenant 默认币种，不做汇率换算。

## 安全与运维

- Spring Security 验证 JWT，普通业务 API 仅允许 `USER` 角色访问，所有业务查询都显式包含 `tenant_id`。
- 无 Tenant 的 `ADMIN` 仅能访问 Tenant、账号、个人资料和管理员审计接口。
- Refresh Token 使用安全 Cookie，并支持轮换和撤销。
- Flyway 负责数据库结构，Hibernate 只执行 `validate`。
- `/actuator/health` 用于健康检查，日志包含 `traceId`。
- 商品原图和低清预览使用短期预签名 PUT URL 上传，Bucket 保持私有；页面通过 Tenant 鉴权的后端接口读取低清预览，不接收 R2 GET URL。
